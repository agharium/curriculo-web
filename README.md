# 🌐 Web Resume — Senac's Web Programming Class of 2026

### 📚 About the Project

This repository was created as part of a hands-on learning activity for the **2026 Web Programming Class at Senac**, designed to introduce teenage students to **Git, GitHub, and version control fundamentals**.

The idea was simple: use a personal resume website built with HTML, CSS, and JavaScript as a practical example to demonstrate how developers track changes, manage code, and collaborate on software projects.

Rather than simply memorizing commands, students were encouraged to understand how version control fits into real-world software development workflows.

## 🎯 Learning Objectives

Throughout this activity, students were introduced to essential concepts and practices, including:

- Understanding version control and its importance in software development.
- Exploring the differences between Git and GitHub.
- Creating and managing Git repositories.
- Tracking code changes through commits.
- Using essential Git commands such as `git init`, `git add`, `git commit`, and `git push`.
- Understanding commit history and project evolution.
- Developing good habits for organizing and documenting code.

## 🛠️ Technologies Used

- **HTML5** — Content structure and semantic markup.
- **CSS3** — Styling and visual presentation.
- **JavaScript** — Interactivity and dynamic behavior.
- **Git** — Version control.
- **GitHub** — Code hosting and repository management.

## 🚀 Learning by Doing

The project provided a practical introduction to the Git workflow:

```bash
# Check the current repository status
git status

# Stage changes
git add .

# Commit changes
git commit -m "Improve resume layout"

# Push changes to GitHub
git push
```

By making changes to a real project, students could observe how Git records development history and helps developers manage their work over time.

## 💡 Beyond the Code

This project reflects a core principle of programming education: **learning by doing**.

By introducing teenagers to tools widely used in the software industry, the activity aimed to build technical confidence, encourage curiosity, and provide a foundation for future personal, academic, and professional projects.

The goal was never to build the most sophisticated resume website. It was to demonstrate that **every great software project starts with small steps — and every commit tells part of the story.**
